🔍 How Randgo groups coupon codes
Randgo bundles vouchers with the same denomination (rand value) into a single scannable barcode. A customer with 5 vouchers may receive 3 barcodes — one covering the 3 x R20 items, one for the R10 item, one for the R5 item. Every barcode is unique to that customer's phone number and cannot be used by another customer.
